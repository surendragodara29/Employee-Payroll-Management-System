# Employee Payroll Management System

## 📌 Project Overview

The Employee Payroll Management System is a Python-based console application developed to simplify and organize employee record management and salary-related operations. The main purpose of this project is to provide an easy-to-use platform where an administrator can efficiently manage employee information, maintain salary records, and perform different employee management operations.

In many organizations, maintaining employee details manually can be time-consuming and may lead to errors, duplication, or difficulties in updating records. This project provides a simple digital solution to these problems by allowing administrators to manage employee information through a menu-driven interface.

The system starts with an admin login facility that provides access to the employee management dashboard. After successful authentication, the administrator can add new employees, remove existing employees, search for and view individual employee details, display all registered employees, and manage their salary information.

This project is developed using Python and demonstrates the practical implementation of fundamental programming concepts such as functions, lists, loops, conditional statements, user input handling, and data management.

## 🚀 Key Features

### 1. Admin Login
The system provides an admin authentication facility. Only users with valid login credentials can access the employee management operations.

### 2. Add Employee
The administrator can register new employees by entering their personal and professional information, including Employee ID, Name, Age, Gender, Department, and Salary.

### 3. Remove Employee
The administrator can remove an employee from the system by entering the employee's name. The corresponding employee information is also removed from the records.

### 4. View Employee
This feature allows the administrator to view the details of a particular employee, making it easier to access individual employee records.

### 5. View All Employees
The administrator can display all registered employees along with their personal details, department information, and salary records.

### 6. Salary Management
The system maintains employee salary information and allows the administrator to access salary details for better payroll record management.

### 7. Logout
The logout option allows the administrator to exit the management dashboard safely.

## ⚙️ Working Process

1. The application starts with the admin login screen.
2. The administrator enters the required username and password.
3. After successful login, the main menu is displayed.
4. The administrator selects an operation from the available options.
5. The system performs the selected operation.
6. Employee information is updated or displayed according to the administrator's choice.
7. The administrator can continue performing operations or select Logout to exit the system.
